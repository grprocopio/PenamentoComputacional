Explique como você utilizaria estruturas if para controlar o sistema:

Eu usaria  if para decidir o que o sistema faz dependendo dos botões e do estado da máquina.
Por exemplo, se eu pressionar iniciar e o sistema estiver parado, eu começo o processo: leio o potenciômetro, defino o tempo e ligo os LEDs certos.
Se eu apertar iniciar enquanto já estiver rodando, eu uso um if para não fazer nada.
Se eu apertar parar, eu uso um if para parar tudo na hora e voltar o sistema para o estado de parado.
Se eu apertar reset, eu uso outro if para desligar tudo e reiniciar o sistema.
E para o segundo potenciômetro, eu uso if para ver o valor e acender 1, 2 ou 3 LEDs dependendo da intensidade.
Basicamente, eu uso if para checar o botão pressionado e o estado do sistema antes de executar qualquer ação.
